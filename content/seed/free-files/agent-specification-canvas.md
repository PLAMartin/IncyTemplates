## Objective

A documented agent specification — goal, architecture pattern, tools and evaluation loop — completed before you start building.

## Intended user

Founders and small teams adding an AI feature to their product without a dedicated AI engineer to advise on architecture.

## Situation

Once you know which of the five design patterns fits (Augmented LLM, Prompt Chaining, Routing System, Orchestrator-Worker, Evaluator-Optimiser), write down the agent's goal, the pattern it uses, the tools or data sources it needs, and how you'll know it's working well.

## Process

1. State the goal — what should the agent accomplish, in one sentence?
2. Confirm the architecture pattern — which of the five fits, and why?
3. List the tools, data sources or memory the agent needs access to.
4. Define the evaluation loop — how will you know it's working well, and what does failure look like?
5. Note the simplest version worth building first.

Expected to take roughly 10–15 minutes per feature.
